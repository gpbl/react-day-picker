title: Persian Calendar
---

DayPicker supports the Persian [Solar Hijri](<https://en.wikipedia.org/wiki/Iranian_calendars#Modern_calendar:_Solar_Hijri_(SH)>) calendar via a dedicated build.

Install the React package and the Persian calendar package:

```bash npm2yarn
npm install @daypicker/react @daypicker/persian
```

Import `DayPicker` from `@daypicker/persian` to render Persian months and weekdays while keeping the usual DayPicker API.

```tsx
import { DayPicker } from "@daypicker/persian";
```

### Farsi labels, Eastern Arabic-Indic digits

```tsx
import { DayPicker, faIR } from "@daypicker/persian";
<DayPicker locale={faIR} />;
```

### Afghan Pashto, Solar Hijri calendar

`psAF` from `@daypicker/persian` uses Afghan Pashto Solar Hijri month names (وری through کب), the Jalali calendar, Saturday as the first day of the week, and Pashto accessibility labels. It displays Pashto month names and Eastern Arabic-Indic digits by default (for example, `تله ۱۴۰۵`).

```tsx
import { DayPicker, psAF } from "@daypicker/persian";

export function Pashto() {
  return <DayPicker locale={psAF} />;
}
```

<BrowserWindow sourceUrl="https://github.com/gpbl/react-day-picker/blob/main/examples/Pashto.tsx">
  <Examples.Pashto />
</BrowserWindow>

For romanized Pashto month names, English weekday labels, and Latin digits, use the `psAFEn` locale:

```tsx
import { DayPicker, psAFEn } from "@daypicker/persian";

<DayPicker locale={psAFEn} numerals="latn" showWeekNumber showOutsideDays />;
```
